# LLD in Python

Code for **LLD in Python**, a YouTube course by **Learn with Yesha**: Low Level Design, one topic at a time, in Python.

> **Understand. Don't memorize.**
> Every episode starts with a real problem, shows the design that breaks, and builds the fix, so you can solve problems you've never seen.

📺 **Playlist:** _coming soon_

## The CLEAR method
Every design problem in this course is solved the same way:

| Step | What you do |
|---|---|
| **C**larify the problem | Ask the right questions, agree on scope |
| **L**ist the entities | Find the objects and what each is responsible for |
| **E**stablish relationships | Decide how they connect; draw the class diagram |
| **A**nticipate change | Spot what will change and design for it |
| **R**ealize in code | Write it, test it, handle follow-ups |

## How this repo is organised
```
03-class-relationships/
└── 015-association/
    ├── README.md   what the episode covers + your exercise
    ├── *.py        code from the episode
    └── test_*.py   run with `pytest`
```
A new episode folder appears the day its video goes live.

1. Watch the episode. 2. Try the exercise **before** opening the code. 3. Compare.

Requirements: Python 3.12+, optional `pip install pytest mypy`.
